# 从道具修正回到叙事与导演

《一起吃》44.5秒版已被用户拒收。它在若干选用区间内解决了披萨转移，却不能因此被称为好作品。

## 没有被局部技术检查解决的事

- 缺少进门和从购买到用餐的场面建立：开场母亲站着、孩子已经坐好，人物来到这里和分配空间的过程没有拍出。
- 问价与赠送过近：没有“先买到半份、再发现母亲让饭、最后赠余半”的行动层次，善意更多是台词宣布。
- 表演在生成片段交接处回到默认状态：脸和衣服接得上，不代表听见了上一句、继承了上一刻的犹豫与视线。
- 相近机位长时间记录对白，后期数码裁切增加景别但没有补足新的场面动作；观众注意力和信息获得顺序没有被充分设计。
- 用可用素材合成出的44.5秒，不能等同于已经通过完整对白试演确认的自然时长；技术检查和逐镜自评不能替代整片创作判断。

## 用户新确定的因果链

母亲带两孩进门 → 看钱后选择半份并付款 → 老板从整份中切出半份 → 母子就座、孩子邀请 → 母亲看分量后推辞 → 老板观察到让饭 → 以打烊不好卖为台阶赠送余半 → 母亲感谢并接受孩子再次邀请 → 三人实际吃。

这条链中，孩子的邀请让老板获得新信息；母亲的推辞引起老板行动；老板的说法让母亲能够接受；孩子第二次邀请回收第一次的推辞。不能只拍动作结果、略去改变决定的时刻。

## 本次交付的层级

1. 完整故事与可演对白：screenplay.md。
2. 人物目的、空间轴线、12镜的切点与接拍状态：directing.md。
3. imagegen内置工具生成并修正的静态图版：storyboard-draft-v2.png；完整提示分别保存。
4. 暂估65秒的静帧预演：story-reel-draft.mp4，无对白音轨、没有演员运动，不是成片或已完成的表演验证。

图版主要用于检查信息与镜头顺序，不能据此批准半份切分、交付、递食物和进食动作。11—12镜的片块数量、缺口和盘子仍需在生产首尾帧与实际动作中规范，不能照图让食物突然少掉。

随后应先完整对白试演，再修订分镜时长；试拍最难的分半交付和母亲接受食物。此文件没有声称这些步骤已经完成。
