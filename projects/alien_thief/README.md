本目录保留角色设定、剧本、分镜配置、参考图及早期生成脚本。资料入库表示可以追溯和继续研究，不表示影片已通过故事、表演或口型验收；此前被拒绝的影片仍保持拒绝状态。

## 历史脚本

这六个脚本保留原有 Windows 路径、依赖及参数，供查阅历史提示词、生成配置和处理逻辑。本次仅检查语法，未加载模型或重新执行生成，也未验证当前提供方是否仍支持其中的模型名称。

| 文件 | 历史用途与限制 |
| --- | --- |
| `generate_real_ai_visuals.py` | 角色与场景图提示词，通过原 Windows `gflow.exe` 生成图片。 |
| `generate_missing_keyframes.py` | 补齐指定关键帧；已有文件可跳过。 |
| `generate_audio.py` | Qwen3-TTS 角色语音与 ACE-Step 配乐试验，需要原模型目录和 GPU 环境；不是跨镜头音色一致性的验收证据。 |
| `render_and_master.py` | 早期静态图绘制动画、字幕及后配音混音试验，不是完整角色表演。 |
| `master_ai_comic_video.py` | 按音量包络绘制嘴部的旧试验，不是音素级口型同步，不作为当前出镜对白制作入口。 |
| `pipeline_master_ep01.py` | 旧语音时长适配和嘴部区域变形试验，包含语音重采样；不用于当前出镜对白交付。 |

新的原生画音剪辑使用仓库的 `scripts/native_av_master.py`，以同一区间裁切同一次生成的画面和原声。该工具的帧与 PCM 检查也不能代替故事、道具连续性、听辨和嘴形审看。历史脚本未接入当前默认流程。
