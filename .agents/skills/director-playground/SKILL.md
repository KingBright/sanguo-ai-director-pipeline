# Google Playground 游戏创作

通过 https://playground.google/ 操作真实服务。按当前设备的 ego-browser 技能执行，先运行 `ego-browser skill`；该浏览器不可用时再使用当前客户端支持的浏览器。没有已验证的公开生成 API，不编造接口或把本地手写游戏说成 Playground 产物。

## 创作和修改

- 从用户意图明确玩家做什么、目标、失败条件、输入方式和美术方向。小样先实现完整可玩的循环；时长是体验目标，不是硬编码结束的替代品。
- 查看当前登录、创建权限和额度。账号验证交给用户在原页面完成；区域限制、候补名单和额度不足如实记录。不要换账号、地区或代理规避限制。订阅权益和登录状态不会随技能安装自动同步。
- 进入“创建 / Create”，提交一次 prompt。需要参考图时使用页面支持的 PNG/JPG 上传；不能把网站的参考图上传说成音频或视频导入能力。多人模式需在初次生成前选择。
- 等待本次任务编译成可玩游戏，保存项目 URL 或界面给出的标识。超时后先到“您的游戏 / Your games”检查已有草稿，不重复提交不明状态的生成。
- 修改已有作品时，从“您的游戏”进入编辑器；每次描述具体玩法或视觉变化，确认结果后继续。创建默认是草稿。只有用户要求分享或发布时才修改可见性；Unlisted 链接也允许持链者访问，不等于私有。

## 试玩与导出

实际使用键盘、鼠标或触屏试玩，至少验证输入有效、目标能够达成、失败或结束状态合理以及重开可用。根据任务检查移动端布局。截图、成功编译和控制台无报错不能单独证明游戏好玩。

在编辑器顶部用 Export / Download Zip 导出，按浏览器技能先监听下载再触发，并保存真实 ZIP。检查文件清单与入口；解压到新的独立目录，拒绝越界路径和符号链接。先检查导出的代码与依赖，再用回环地址的静态服务试玩，不能假定离线可用。

用户需要角色语音或配乐时，可按需调用 `director-speech` / `director-bgm`；若网页未提供音频导入，应在已导出的项目里集成音轨，明确这是导出后的本地修改。视频制作继续使用 `director-story`，不改变其流程。

交付实际项目入口、ZIP 路径、可见性、试玩结果和未验证项。仅写好 prompt 或安装技能时不能报告“游戏已生成”。

官方帮助与额度规则：https://playground.google/helpcenter 。当前公开说明限美国18岁以上，创建额度按周刷新，家庭成员不能合并创作额度；使用时以当前账号界面及最新帮助为准。
