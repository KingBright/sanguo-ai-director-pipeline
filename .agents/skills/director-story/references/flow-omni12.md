# Flow Omni 1.2 Flash 原生画音与接续

2026-11-07 已在 flow.google.com 的 Ultra 账号实际看到模型菜单 `Omni 1.2 Flash`（音频标识），720p、15秒、x1显示60点。本记录不是固定费率表，执行时读取当前页面报价。

使用 ego-browser 操作网页，先运行其技能。旧 gflow 的 `omni-flash` 名称不能证明请求的是1.2；未核实CLI映射前，使用网页明确选择新模型，记录模型、分辨率、时长、数量和报价。不要修改旧视频路线默认模型。

时长控件可能是range，DOM值是索引而非秒数。用键盘调整，并核对界面实际显示；不要用fill写秒数。先生成一条带完整对白、停顿和听者反应的试镜，保留原生声音。逐句检查发音、说话者归属、音色和嘴形。模型有音频图标不能作为同步合格证据。

接续必须从选中的上一段使用界面 Extend/延长入口。记录父素材和子素材、真实新增时长以及下载内容是完整链还是新增部分，避免重复拼接。每次先检查末尾人物、道具、位置和声音状态，再写下一段情节。使用参考图引导仅在当前延长界面支持时操作。不能把独立重新生成或末帧图生视频说成原生接续。

约60秒是故事体量目标，不预设每次扩展都能加15秒。让角色行动完成冲突与结局；按实际新增时长调整接续次数。切点保留原声与画面相同区间，不用TTS替换出镜对白，不变速赶词。结果必须区分实际生成、技术检查、听辨与嘴形观察、用户评审。

现场已验证入口：素材菜单“添加到场景 → 新建场景”，打开场景，在末尾“添加片段 → 延续镜头”。本次账号初始15秒，接续时长滑块上限10秒。选择模型本身不自动把素材加入场景。

已遇到的限制：35秒素材的“延续镜头”被禁用，控件说明为“视频时长需短于30秒才能延续镜头”。不要绕过禁用。可在场景时间轴合适停顿处分割，保留前段，选择短于30秒的尾段作为后续接续输入。拆分后重新检查时长、画音与身份连续性。超过15秒的整段编辑限制与接续入口是不同限制，不要点自动剪辑丢掉已完成内容。

拆分后的“重新延续镜头”可能重新带回源素材上下文，导致场景出现重复时长；必须下载后核对，不能只按时间轴总时长交付。尾段的重新生成按钮可能覆盖大部分缩略图，选片应避开按钮，先观察选中状态。下载完整场景期间固定时间轴，长场景导出可能超过90秒，延长监听等待，不同时拆分或生成。
