# 第 2 集：栈道辨时·急赴祁山（V2 正式打磨版）

## 故事梗概与“Cos服+双眼镜”伏笔展开
顾渊身穿自带的诸葛亮同款素白鹤氅、手持白羽扇、鼻梁上架着黑框眼镜匆匆下山。正在悬崖泥潭边绝望怒吼的蜀汉押粮都尉王巡与士卒们一见他这身“武侯同款”仙风道骨的行头，再看他鼻梁上闪烁寒光的“水晶镜”，顿时惊为天人，误以为是丞相秘派的奇门高徒！
面对断裂下坠的千斤粮车，顾渊用大学工科常识与游戏里的工程器械思路，指挥士卒砍原木作杠杆、藤索作动滑轮组，三分钟将粮车稳稳拉回栈道；随后更从胸前眼镜盒里取出**第二副备用金属框眼镜**，与手头镜片一前一后叠在竹筒两端，做成简易“单筒望远镜”远眺前方山口塌方路况，彻底折服全军！
当王巡恭敬递上通关竹简，顾渊透过镜片看清上面的墨字：**“建兴六年春·督运汉中粮料发祁山大营”**！
顾渊瞳孔骤缩——**建兴六年春！第一次北伐！** 张郃的五万铁骑正在杀奔街亭的路上，而马谡即将立下军令状上山！
